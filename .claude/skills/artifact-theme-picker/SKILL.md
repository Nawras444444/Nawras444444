# Artifact Theme Picker

This skill applies a consistent color and font theme to an artifact, such as a slide deck, document, report, or HTML landing page. It has ten preset themes. If none fits, it creates a new one.

## Usage

1. **Show the choices.** List the ten themes below, each with its palette and best use, so the user can compare them.
2. **Ask for the choice.** Ask which theme to apply, or whether a custom theme is needed.
3. **Wait for explicit confirmation** of the chosen theme.
4. **Apply it.** Use the theme's colors and fonts consistently across the artifact. Check contrast and readability, and keep the theme's identity on every page or section.

For each theme: palette hex codes, font pairing (headers / body), and best use.

## Custom themes

If no preset fits, create a new theme from the user's description. Name it after what its colors and fonts represent. Choose 3 to 4 hex colors (a dark base, a primary accent, a secondary accent, and a light background or text color) and a header/body font pair from the fonts above. Show the theme for review, and apply it only after the user approves.
